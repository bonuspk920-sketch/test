1สร้างชีตและกรอกรายชื่อ

  1. เปิดแท็บใหม่ พิมพ์ sheets.new ในช่อง URL แล้วกด Enter จะได้สเปรดชีตเปล่า
  2. กดที่คำว่า “สเปรดชีตไม่มีชื่อ” มุมซ้ายบน เปลี่ยนเป็น ทำเนียบสมาชิกกลุ่ม
  3. คลิกช่อง A1 แล้วพิมพ์ 3 คำนี้ไล่ไปทางขวา กด Tab เพื่อขยับช่อง
    A1B1C1
    เลขที่ชื่อ-นามสกุลชื่อเล่น
  4. กรอกข้อมูลสมาชิกในกลุ่มตั้งแต่แถวที่ 2 ลงมา กี่คนก็ได้
ห้ามพลาดอย่าสลับคอลัมน์ และอย่าเว้นแถวว่างคั่นกลาง เพราะเดี๋ยวโค้ดจะอ่านตามลำดับ A → B → C ถ้าสลับ ชื่อกับเลขที่จะไปโผล่ผิดที่
ความปลอดภัยเว็บนี้จะเปิดให้ทุกคนดูได้ ห้ามใส่เลขบัตรประชาชน เบอร์โทร ที่อยู่ หรือรหัสผ่านลงในชีตเด็ดขาด ใส่แค่ 3 ช่องนี้พอ

2เปิดห้องเขียนโค้ด

  1. อยู่ในชีตเดิม กดเมนูด้านบนที่คำว่า ส่วนขยาย (Extensions)
  2. เลือก Apps Script — จะมีแท็บใหม่เด้งขึ้นมา นี่คือห้องเขียนโค้ดของเรา
  3. ในแท็บใหม่ กดที่ “โครงการไม่มีชื่อ” ด้านบน เปลี่ยนชื่อเป็น ทำเนียบสมาชิก
ทำไมต้องเปิดจากในชีตเปิดแบบนี้ Apps Script จะจำได้เองว่าต้องไปเอาข้อมูลจากชีตใบไหน ถ้าไปเปิดจากที่อื่น มันจะไม่รู้จักชีตของเราและดึงข้อมูลไม่ได้
ขั้นที่ 3

3วางโค้ดหลังบ้าน (Code.gs)

  1. คลิกในช่องโค้ดตรงกลางจอ กด Ctrl+A เพื่อเลือกทั้งหมด แล้วกด Delete ให้หน้าจอว่างเปล่า
  2. กดปุ่ม คัดลอกโค้ด ในกล่องข้างล่าง
  3. กลับมาที่ Apps Script กด Ctrl+V วางลงไป
  4. กด Ctrl+S เพื่อบันทึก
Code.gs 
function doGet() {
  return HtmlService.createTemplateFromFile('index')
    .evaluate()
    .setTitle('Member Dashboard')
    .addMetaTag('viewport', 'width=device-width, initial-scale=1');
}

function getMembers() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = sheet.getDataRange().getValues();
  data.shift(); // ลบหัวตาราง
  return data;
}

4วางโค้ดหน้าเว็บ (index.html)

  1. ทางซ้ายมือ ตรงหัวข้อ ไฟล์ กดเครื่องหมาย + แล้วเลือก HTML
  2. มันจะให้ตั้งชื่อไฟล์ พิมพ์ว่า index แล้วกด Enter
  3. ในไฟล์ใหม่จะมีโค้ดตัวอย่างอยู่ กด Ctrl+A แล้ว Delete ให้ว่าง
  4. กดปุ่มคัดลอกด้านล่าง แล้ววางลงไป จากนั้นกด Ctrl+S
จุดที่พลาดกันเยอะที่สุดตอนตั้งชื่อไฟล์ให้พิมพ์แค่ index เท่านั้น ห้ามพิมพ์ .html ต่อท้าย เพราะระบบเติมให้เองอยู่แล้ว ถ้าพิมพ์เกินจะกลายเป็น index.html.html แล้วเว็บจะเปิดไม่ขึ้น

ขั้นที่ 5

5ปล่อยเว็บให้ได้ลิงก์

ขั้นนี้มีหน้าจอเยอะ แต่ทำครั้งเดียวจบ ค่อย ๆ ทำตามภาพทีละจอ

5.1 เปิดเมนู

กดปุ่มสีน้ำเงินมุมขวาบน การทำให้ใช้งานได้ แล้วเลือก การทำให้ใช้งานได้รายการใหม่

5.2 เลือกประเภทเป็น เว็บแอป

กด ไอคอนฟันเฟือง ข้างคำว่า “เลือกประเภท” แล้วเลือก เว็บแอป

5.3 ตั้งสิทธิ์

  • ดำเนินการในฐานะ — ปล่อยเป็นชื่อเราไว้ ห้ามเปลี่ยน
  • ผู้มีสิทธิ์เข้าถึง — เปลี่ยนเป็น ทุกคน
  • แล้วกดปุ่ม การทำให้ใช้งานได้

5.4 ให้สิทธิ์

กด ตรวจสอบสิทธิ์ แล้วเลือกบัญชี Google ของเราเอง

5.5 ผ่านหน้าจอสีแดง

จะเจอหน้าจอ “Google ยังไม่ได้ยืนยันแอปนี้” ไม่ต้องตกใจ มันขึ้นเพราะสคริปต์นี้เราเขียนเอง ยังไม่เคยส่งให้ Google ตรวจ

  1. กดคำว่า ขั้นสูง มุมล่างซ้าย
  2. จะมีลิงก์เล็ก ๆ โผล่มา กด ไปที่ ทำเนียบสมาชิก (ไม่ปลอดภัย)
  3. กด อนุญาต
จำไว้ใช้ในชีวิตจริงหน้าจอนี้ปลอดภัยเพราะเราเป็นคนเขียนสคริปต์เอง แต่ถ้าเจอหน้าจอแบบนี้จากลิงก์ที่คนอื่นส่งมา ให้กด “กลับสู่ความปลอดภัย” เสมอ

5.6 เก็บลิงก์

จะได้ URL ที่ขึ้นต้นด้วย https://script.google.com/macros/s/… กด คัดลอก แล้วลองเปิดในแท็บใหม่ และลองเปิดในมือถือด้วย

ขั้นที่ 6

6ทดสอบว่าเว็บทำงานจริง

ทำ 3 ข้อนี้ ถ้าผ่านหมดแปลว่าส่วน A เสร็จสมบูรณ์

  1. นับการ์ด — จำนวนการ์ดต้องเท่ากับจำนวนคนในชีต ไม่นับหัวตาราง
  2. ดูใบแรก — ต้องไม่มีการ์ดที่เขียนว่า “เลขที่ เลขที่ / ชื่อ-นามสกุล”
  3. ทดสอบข้อมูลสด — กลับไปแก้ชื่อในชีตสักชื่อ แล้วรีเฟรชหน้าเว็บ ชื่อต้องเปลี่ยนตาม
ข้อ 3 สำคัญที่สุดมันพิสูจน์ว่าเว็บของเราไม่ได้พิมพ์ชื่อแปะไว้ตายตัว แต่วิ่งไปดึงข้อมูลสดจากชีตทุกครั้งที่เปิด
ติดตรงไหน เปิดดูตรงนี้

?อาการที่เจอกันบ่อย

เปิดลิงก์แล้วหน้าขาว ไม่มีการ์ดเลย
ไล่เช็ก 3 อย่าง 1) ชีตมีข้อมูลตั้งแต่แถวที่ 2 ลงไปจริงไหม 2) ชื่อไฟล์ HTML เป็น index ไม่ใช่ index.html ใช่ไหม 3) คำว่า getMembers ในสองไฟล์สะกดเหมือนกันไหม (ตัวใหญ่ตัวเล็กมีผล)
การ์ดใบแรกเขียนว่า “เลขที่ เลขที่”
บรรทัด data.shift(); ใน Code.gs หายไปหรือพิมพ์ผิด บรรทัดนี้มีหน้าที่ทิ้งแถวหัวตาราง เติมกลับแล้วบันทึกใหม่
ขึ้นว่า Script function not found: doGet
ระบบหาฟังก์ชัน doGet ไม่เจอ มักเกิดจากลบโค้ดเก่าไม่หมดแล้ววางทับ หรือกด Deploy ตอนที่ยังไม่ได้บันทึก ให้กด Ctrl+S แล้วปล่อยเวอร์ชันใหม่
แก้โค้ดแล้ว แต่เปิดลิงก์เดิมยังเห็นของเก่า
อันนี้ไม่ใช่บั๊ก มันเป็นแบบนั้นเอง ลิงก์ที่ปล่อยไปแล้วจะค้างอยู่ที่รุ่นเดิมเสมอ วิธีอัปเดตอยู่ในส่วน B หัวข้อ “แก้โค้ดแล้วต้องปล่อยรุ่นใหม่”
เพื่อนเปิดแล้วขึ้นว่าไม่มีสิทธิ์เข้าถึง
ตอน Deploy ตั้ง ผู้มีสิทธิ์เข้าถึง ไว้เป็น “ฉันเท่านั้น” แก้เป็น ทุกคน แล้วปล่อยรุ่นใหม่
ภาษาไทยกลายเป็นตัวประหลาด
เพิ่มบรรทัด <meta charset="utf-8"> ไว้ใน <head> ของ index.html

โจทย์

Bทำให้เว็บ “เพิ่มสมาชิกได้” จากหน้าเว็บ

ตอนนี้เว็บของเราอ่านข้อมูลได้อย่างเดียว ถ้าจะเพิ่มคนต้องไปเปิดชีตพิมพ์เอง ซึ่งไม่สะดวก

ภารกิจคือ ทำให้หน้าเว็บมีช่องกรอกกับปุ่มกด กดแล้วชื่อใหม่ไปโผล่ในชีตจริง ๆ

ไม่มีเฉลยส่วนนี้ไม่มีโค้ดให้คัดลอก ต้องคุยกับ AI เอาเอง — นี่คือคะแนนของงานชิ้นนี้ ไม่ใช่โค้ดที่ได้มา แต่คือความสามารถในการสั่งงาน ทดสอบ และแก้จนใช้ได้

ก่อนไปคุยกับ AI

!4 เรื่องที่ต้องรู้ ไม่งั้นเสียเวลาทั้งคาบ

1. AI มองไม่เห็นหน้าจอเรา

มันไม่รู้ว่าเราใช้ Apps Script ไม่รู้ว่าชีตหน้าตายังไง ไม่รู้ว่าโค้ดเราตอนนี้เป็นแบบไหน ทุกครั้งที่ถาม ต้องเล่าให้ฟังก่อน แล้ววางโค้ดปัจจุบันไปด้วย ถ้าไม่บอก มันจะเดาว่าเป็นเว็บธรรมดาแล้วให้โค้ดที่ใช้ไม่ได้เลย

2. AI ฟรีความจำสั้น

คุยไปหลาย ๆ รอบมันจะเริ่มลืมว่าโค้ดเราหน้าตายังไง ถ้ารู้สึกว่าคำตอบเริ่มมั่ว ให้เปิดแชทใหม่ แล้ววางโค้ดล่าสุดไปให้อีกครั้ง

3. ขอทีละอย่าง

อย่าสั่งว่า “ทำฟอร์ม เพิ่มปุ่มลบ เพิ่มช่องค้นหา และเปลี่ยนสี” พร้อมกัน เพราะพอพังจะไม่รู้ว่าพังเพราะอะไร ทำให้เสร็จทีละอย่าง ทดสอบให้ผ่าน แล้วค่อยขออย่างต่อไป

4. แก้โค้ดแล้วต้องปล่อยรุ่นใหม่

นี่คือเรื่องที่คนติดกันเยอะที่สุด แก้โค้ดแล้วกดบันทึกอย่างเดียว ลิงก์เดิมจะยังเป็นของเก่า ต้องทำแบบนี้ทุกครั้ง

  1. กด การทำให้ใช้งานได้ > จัดการการทำให้ใช้งานได้
  2. กด ไอคอนดินสอ มุมขวาบนของหน้าต่าง
  3. ช่อง เวอร์ชัน เปลี่ยนเป็น เวอร์ชันใหม่
  4. กด ทำให้ใช้งานได้ — ลิงก์เดิมจะกลายเป็นโค้ดใหม่ทันที
ทางลัดตอนนั่งแก้ระหว่างที่ยังลองผิดลองถูกอยู่ ให้ใช้ การทำให้ใช้งานได้ > การนำการทดสอบไปใช้งาน แทน ลิงก์ทดสอบจะอัปเดตตามโค้ดล่าสุดทุกครั้งที่กดบันทึก ไม่ต้องปล่อยรุ่นใหม่ทุกรอบ แต่ลิงก์นี้เปิดได้แค่บัญชีเราเอง พอทำเสร็จค่อยปล่อยรุ่นใหม่ให้ลิงก์จริง
ระวังตอนเว็บเขียนข้อมูลได้แล้วพอเว็บเพิ่มแถวลงชีตได้ แปลว่าใครก็ตามที่ได้ลิงก์ไปก็เพิ่มแถวได้ ให้ส่งลิงก์เฉพาะในห้องเรียน และถ้ามีคนแกล้งกรอกมั่ว ก็เข้าไปลบแถวในชีตได้ตามปกติ

✎สร้างคำสั่งไปถาม AI

เลือกสิ่งที่อยากทำ แล้วกดคัดลอกคำสั่งไปวางใน AI ที่ใช้อยู่ ใช้ได้ทั้ง Gemini, ChatGPT, Copilot หรือตัวไหนก็ได้ที่เป็นของฟรี

อย่าลืมหลังวางคำสั่งนี้แล้ว ให้วางโค้ดปัจจุบันของทั้งสองไฟล์ต่อท้ายไปด้วย AI ถึงจะแก้ให้ตรงกับของเราได้

ถ้าทำตามแล้วยังไม่ได้ ใช้แบบฟอร์มนี้

ฉันแก้โค้ดตามที่แนะนำแล้ว แต่ยังไม่ได้ผล อาการที่เห็นบนหน้าจอ: (เห็นอะไร เช่น หน้าขาว / กดปุ่มแล้วไม่มีอะไรเกิดขึ้น / ชีตไม่มีแถวใหม่) ข้อความ error: (เปิด "บันทึกการดำเนินการ" ใน Apps Script แล้วคัดลอกมาวางทั้งหมด ถ้าไม่มีให้บอกว่าไม่มี) ฉันแก้ไฟล์ไหนไปบ้าง: (Code.gs หรือ index.html หรือทั้งสอง) ฉันปล่อยเวอร์ชันใหม่แล้วหรือยัง: (ตอบใช่หรือไม่) โค้ดปัจจุบันของฉัน Code.gs: (วางทั้งไฟล์) index.html: (วางทั้งไฟล์) ช่วยหาสาเหตุ บอกวิธีแก้ทีละขั้น และอธิบายว่าทำไมถึงเกิดปัญหานี้ ด้วยภาษาที่นักเรียน ม.4 เข้าใจ
